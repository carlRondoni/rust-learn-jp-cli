# Train Japanese CLI

This is a CLI for train Japanese on your terminal.

## Requirements

- [Rust](https://www.rust-lang.org/)

## Usage

```bash
cargo run
```

## Features

- Select from Hiragana and Katana in endless mode.
- Includes basic, dakuten, handakuten and combinations.
- answer with romaji or written character.
